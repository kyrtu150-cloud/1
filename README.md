# СОК.ai

AI-сервис для создания продающего визуала карточек товаров на маркетплейсах
(Wildberries, Ozon, Я.Маркет). Загружаешь 3–6 фото с телефона — получаешь
полноценную фотоворонку: обложки для A/B-теста, ракурсы, детали, инфографику
и видео-обложку.

Это новая версия сайта (v2): редизайн лендинга + внутренний интерфейс
(**Студия**) с полем ввода промта, вдохновлённый воркспейсом Higgsfield, и
модульным слоем подключения нейросетей.

## Стек

- **Vite + React 18 + TypeScript**
- **React Router** — лендинг (`/`) и студия (`/studio`)
- Чистый CSS с дизайн-токенами (палитра и шрифты сохранены из брифа:
  Plus Jakarta Sans + JetBrains Mono)
- Без тяжёлых UI-библиотек

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # типизация + продакшен-сборка в dist/
npm run preview    # предпросмотр собранного билда
```

## Подключение нейросетей

Весь доступ к генерации идёт через `src/lib/api`. UI знает только про функцию
`generate()` — конкретная нейросеть выбирается реестром провайдеров.

**Чтобы добавить новую нейросеть:**

1. Создайте `src/lib/api/providers/<name>.ts` с классом, реализующим интерфейс
   `GenerationProvider` (см. `src/lib/api/types.ts`).
2. Зарегистрируйте провайдер в `src/lib/api/providers/index.ts`
   (массив `ALL_PROVIDERS`).
3. Добавьте ключи в `.env` (см. `.env.example`).

В комплекте уже есть провайдеры:

| Провайдер   | Файл                          | Назначение                          |
|-------------|-------------------------------|-------------------------------------|
| `mock`      | `providers/mock.ts`           | Демо без API (по умолчанию)         |
| `openai`    | `providers/openai.ts`         | OpenAI Images / совместимый эндпоинт|
| `replicate` | `providers/replicate.ts`      | Replicate (Flux, SDXL)              |
| `custom`    | `providers/custom.ts`         | Ваш собственный бэкенд (рекомендуется для продакшена) |

```bash
cp .env.example .env
# например:
# VITE_GENERATION_PROVIDER=replicate
# VITE_REPLICATE_API_TOKEN=r8_...
```

> ⚠️ Переменные `VITE_*` попадают в браузерный бандл. Секретные ключи в
> продакшене держите на своём бэкенде и используйте провайдер `custom`.

## Демо-режим и фото

По умолчанию активен провайдер `mock`: интерфейс полностью кликабельный без
ключей, а вместо заглушек используются **реальные фотографии** (Unsplash CDN)
из `src/data/showcase.ts` — те же, что демонстрируют возможности на лендинге.
